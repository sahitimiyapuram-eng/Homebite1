# Homebite - Healthy Home Food Without Daily Planning

A complete, production-grade frontend web application built with **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Vite**.

Designed specifically according to the warm, cozy earthy aesthetic:
- **Palette**: Deep Cocoa (`#4B2E25`), Warm Terracotta (`#AE7C53`), Soft Biscuit (`#DEB89D`), Cream Canvas (`#FFFBF0`)
- **Typography**: Poppins & Outfit
- **Theme**: Day Mode & Dark Mode with one-click toggle
- **Responsive**: Full Laptop Desktop Interface + Interactive Mobile Phone chassis view

---

## 🚀 How to Run in VS Code

1. **Extract the ZIP file** to a folder on your computer.
2. Open the folder in **Visual Studio Code** (`File` > `Open Folder...`).
3. Open a terminal in VS Code (`Ctrl + ~` or `Cmd + ~`).
4. Install dependencies:
   ```bash
   npm install
   ```
5. Start the local development server:
   ```bash
   npm run dev
   ```
6. Open your browser at `http://localhost:3000` (or the port displayed in your terminal).
